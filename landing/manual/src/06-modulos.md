# Catálogo de módulos

Telar agrupa el trabajo clínico en **módulos**. Cada uno es una ficha o intervención que se coloca en una sesión.

## Categorías

1. **Conceptualización** — registro inicial, motivo, diagnóstico, nota de sesión, redes de apoyo, plan de seguridad
2. **Pruebas** — escalas con scoring (ASRS, GAD-7, PCL-5, DASS-21, etc.)
3. **Habilidades y tareas (TCC)** — ABC, sesgos, socrático, activación, exposición, etc.
4. **Narrativa / significado** — externalización, felt sense, pregunta milagro, etc.
5. **Intervención** — neurofeedback Muse 2, estimulación bilateral

## Dónde ver el detalle

- En la web: [telarapp.cl/modules](https://telarapp.cl/modules) — fichas con autor, rango etario, confiabilidad y validez en Chile cuando aplica
- En la app: librería de módulos / selector al añadir a una sesión

## Cómo se usan en consulta

1. Abrí el workspace del tratamiento
2. Elegí o creá la sesión
3. Añadí el módulo
4. Completalo en sesión (o como tarea entre sesiones si es un handout)
5. Autosave; exportá PDF si el módulo lo permite

## Packs

La app comercial incluye packs clínicos (por ejemplo base compartida, TDAH adulto, trauma). El repositorio público open core incluye el pack **demo**. Importar/exportar `.telarpack` permite compartir módulos personalizados entre instalaciones.

## Límites

Algunos instrumentos pueden estar pendientes de permiso de licencia y no aparecen en el catálogo público hasta entonces. Los módulos no diagnostican ni prescriben.
