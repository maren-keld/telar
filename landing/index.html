Seguimiento clínico

Cuando el seguimiento está disperso

Notas, escalas y materiales quedan en archivos separados. Comparar resultados o retomar el objetivo de una sesión exige reconstruir el caso manualmente.

Con Telar

Cada sesión reúne objetivos, módulos, escalas y resultados. La evolución queda visible dentro del programa de tratamiento y los datos permanecen en tu equipo.

Un flujo clínico, sesión a sesión.

Instalación

Cómo instalar

Descarga la app completa desde GitHub Releases.

macOS

Si macOS dice «Telar not opened» / «No se abrió Telar»: no uses Mover a la Papelera. Cierra el diálogo, ve a la carpeta donde descomprimiste el .zip, clic derecho en Telar.app → Abrir y confirma. Solo la primera vez.

  1. Descarga Telar-macos.zip y descomprímelo.
  2. Arrastra Telar.app a Aplicaciones.
  3. La primera vez: clic derecho → Abrir (no doble clic).
  4. Si macOS bloquea: Ajustes del Sistema → Privacidad y seguridad → Abrir de todas formas.
  5. Configura tu PIN y, si tu Mac lo permite, Touch ID.

Para quitar la advertencia sin pasos manuales hace falta notarización Apple (Apple Developer Program, ~USD 99/año). En beta, clic derecho → Abrir es normal para apps independientes.

Windows 10/11

Si SmartScreen aparece: Más información → Ejecutar de todas formas. Es normal en apps sin certificado de editor (beta).

  1. Descarga Telar-windows.exe.
  2. Completa el asistente y abre Telar desde el menú Inicio.
  3. Configura tu PIN de 6 dígitos.

Quitar SmartScreen del todo requiere certificado de firma de código (~USD 189/año). Microsoft Store no es gratis ni instantáneo. Para beta, «Ejecutar de todas formas» es la vía estándar.
