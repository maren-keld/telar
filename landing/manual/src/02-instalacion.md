# Instalación y primer acceso

Guía condensada. Si preferís capturas paso a paso, usá el tutorial visual [Cómo instalar Telar](https://telarapp.cl/blog/como-instalar-telar).

## Requisitos

- macOS reciente o Windows 10/11
- Descargar solo desde [telarapp.cl/descargar](https://telarapp.cl/descargar) o el [repositorio oficial](https://github.com/maren-keld/telar/releases/latest)

## macOS

1. Descargá `Telar-macos.zip` desde la página de descargas.
2. Descomprimí y arrastrá **Telar.app** a Aplicaciones.
3. Primera apertura: clic derecho → **Abrir** (solo la primera vez).
4. Si Gatekeeper bloquea la app: Ajustes del Sistema → Privacidad y seguridad → **Abrir de todos modos**. No la muevas a la papelera.

## Windows 10/11

1. Descargá `Telar-windows.exe`.
2. Ejecutá el instalador y seguí el asistente.
3. Si aparece SmartScreen: **Más información → Ejecutar de todas formas**. Telar está en beta y el instalador puede no tener certificado de editor todavía.

## Crear el PIN

Al abrir Telar por primera vez creás un **PIN de seis dígitos**. Ese PIN protege (y desbloquea) la base de datos clínica encriptada en tu equipo.

- Anotalo en un lugar seguro. **Si lo olvidás, Telar no puede recuperar las fichas.**
- En Mac, si el sistema lo permite, podés usar Touch ID en aperturas siguientes.

## Onboarding

Tras el PIN, Telar puede pedir nombre y correo del profesional (contacto y suscripción). Eso no envía la ficha clínica a servidores de Telar.

## Actualizaciones

Las versiones nuevas se publican en GitHub Releases y en la página de descargas. Instalá sobre la versión anterior; los datos locales permanecen en el equipo.
